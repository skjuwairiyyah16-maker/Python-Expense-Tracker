Python Expense Tracker

A simple and interactive expense tracking application built using Python and Streamlit.

Features

- Add new expenses
- Select expense categories
- Enter expense amount and date
- View all recorded expenses
- Calculate total recorded expenses
- Visualize category-wise spending using charts

Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

Installation

Install the required libraries:

pip install -r requirements.txt

How to Run

Run the following command in the terminal:

streamlit run expense_dashboard.py

Project Purpose

This project helps users record, manage, and visualize their daily expenses through a simple dashboard.
